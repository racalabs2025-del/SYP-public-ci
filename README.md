# SYP Public CI Mirror

This repository is a history-free, privacy-sanitized mirror used only to run
the SYP quality gate on GitHub Actions without paid private-repository minutes.

It intentionally excludes operational records, personal data, private reports,
deployment credentials, generated backups, and the original Git history. The
Firebase configuration is a non-deployable placeholder. The canonical source
repository remains private.
